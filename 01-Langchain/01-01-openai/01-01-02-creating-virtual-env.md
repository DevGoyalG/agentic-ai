# Creating Virtual Environment using Conda

## 1. Open the Project Folder

Open your project folder:

```text
D:\agentic-ai\01-Langchain
```

## 2. Open Terminal as Command Prompt

Inside the project folder:

* Right-click in the folder
* Select **Open in Terminal**
* Select **Command Prompt (cmd)** if needed

## 3. Create a Virtual Environment

Run:

```bash
conda create -p venv python==3.10
```

This will create the virtual environment inside:

```text
D:\agentic-ai\01-Langchain\venv
```

## 4. Activate the Virtual Environment

Run:

```bash
conda activate D:\agentic-ai\01-Langchain\venv
```

After activation, you should see something like:

```text
(D:\agentic-ai\01-Langchain\venv) D:\agentic-ai\01-Langchain>
```

Your Conda virtual environment is now activated.
